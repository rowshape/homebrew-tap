# rowshape/homebrew-tap

The Homebrew tap for [**rowshape**](https://github.com/rowshape/rowshape) — the
type-checker for database migrations.

```sh
brew install rowshape/tap/rowshape
rowshape --help
```

`brew install --cask rowshape/tap/rowshape` is the explicit form if you prefer it.

## What is in here

`Casks/rowshape.rb`, and nothing else worth editing.

The cask is **generated by [GoReleaser](https://goreleaser.com) on every tagged
release** of the main repo and committed here automatically. It carries the
version, the download URL, and the SHA-256 of each platform archive.

Do not hand-edit it. The next release overwrites the file, and a hand-edited
checksum is worse than a stale one — Homebrew would refuse the download with a
mismatch that points at this repo rather than at the release that actually
changed.

Every released archive is also published with an SBOM and a
[cosign](https://github.com/sigstore/cosign) signature. To verify a download
yourself rather than trusting the checksum in this file, see the
[release page](https://github.com/rowshape/rowshape/releases).

## Other ways to install

The tap is one of five channels. See
[rowshape.com/install](https://rowshape.com/install/) for `go install`, the npm
wrapper, the `FROM scratch` Docker image, and direct binary downloads.

## Issues

File them against [rowshape/rowshape](https://github.com/rowshape/rowshape/issues),
not here — this repo holds generated output, so a problem with the cask is almost
always a problem with the release that produced it.
